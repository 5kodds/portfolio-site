02How I work

Frame, make, learn.

  • 01 / Frame

    Find the underlying problem.

    Separate the user need from the first proposed solution and define what success would look like.

  • 02 / Make

    Constrain the first release.

    Use requirements, journeys, trade-offs and clear acceptance criteria to make a usable MVP.

  • 03 / Learn

    Test where reality pushes back.

    Investigate behavior, surface risk, collect feedback and prioritize the next change.
